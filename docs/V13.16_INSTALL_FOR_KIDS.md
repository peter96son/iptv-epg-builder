# КАК УСТАНОВИТЬ — ПО ШАГАМ

## Шаг 1. Распаковать ZIP

Внутри ZIP уже лежат папки как в GitHub.
Не переименовывай файлы.

## Шаг 2. Загрузить файлы в GitHub

Открой репозиторий `peter96son/iptv-epg-builder`.

Замени/добавь файлы из ZIP, сохраняя папки:

- `data/playlist_rules.json`
- `data/metadata_overrides.json`
- `src/verified_metadata_fixes.py`
- `tests/test_verified_metadata_fixes.py`
- `run.py`
- `.github/workflows/deploy-worker.yml`
- `cloudflare-worker/wrangler.jsonc`

Нажми `Commit changes`.

## Шаг 3. Проверить плейлист СРАЗУ

Поскольку живой Worker v2.1 уже умеет читать `playlist_rules.json`,
для удаления украинских групп и переносов новый deploy не требуется.

Открой старую ссылку Worker, но в конце добавь:

`/tv?fresh=1`

После этого:
- `Украинские` не должно быть;
- `Кинозалы UA` не должно быть;
- `KBC -Animals HD` должен быть в `Познавательные`;
- `Fresh TV Armenia` должен быть в `Музыкальные`.

## Шаг 4. Исправить EPG «Два капитана»

GitHub → `Actions` → `Update EPG` → `Run workflow`.

После завершения новый `epg.xml.gz` уже пройдёт verified metadata correction.

## Шаг 5. Один раз включить автоматический Cloudflare deploy

Чтобы дальше Worker обновлялся сам:

### 5a. Cloudflare API Token
Cloudflare Dashboard → My Profile → API Tokens → Create Token.
Выбери шаблон `Edit Cloudflare Workers`.
Скопируй токен.

### 5b. Cloudflare Account ID
Cloudflare Dashboard → Workers & Pages.
Найди `Account ID` и скопируй.

### 5c. Добавить оба значения в GitHub
GitHub repo → Settings → Secrets and variables → Actions → New repository secret.

Создай:
- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`

Значения никому не отправляй и в файлы не вставляй.

### 5d. Первый автоматический deploy
GitHub → Actions → `Deploy Cloudflare Worker` → `Run workflow`.

Если зелёная галочка — готово.
Дальше изменение `cloudflare-worker/**` будет само выкатываться в Cloudflare.

`keep_vars: true` специально добавлен, чтобы Wrangler сохранял переменные,
которые были настроены в Cloudflare Dashboard. Зашифрованный `PLAYLIST_URL`
в GitHub не кладём.
