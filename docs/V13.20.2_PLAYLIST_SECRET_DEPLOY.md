# v13.20.2 — PLAYLIST_URL deploy fix

The deploy workflow now uploads the existing GitHub Actions secret `PLAYLIST_URL`
into Cloudflare Worker secrets before running `wrangler deploy`.

The IPTV URL remains secret and is not written to the public repository.

After installing:
1. Commit.
2. Run Actions -> Deploy Cloudflare Worker.
3. Check `/health`.
4. Then open `/tv?fresh=1`.

No Update EPG run is required for this patch.
