# v13.13.3 — CPS family +2h

All `openbox-tsd` source IDs matching `cps-*` now receive +120 minutes.
Both start and stop shift together. Non-CPS channels and CPS from other sources
are untouched. The old +14h CPS USSR rule remains disabled.

The loader now supports a terminal `*` prefix rule in source_id.
Exact rules still take priority over prefix rules.
