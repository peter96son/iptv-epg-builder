# v13.18 — series + Insomnia + year normalization

Verified against the uploaded provider M3U and `epg.xml-5.gz`.

## Changes

- Adds **28** serial-oriented channels from provider group `Кино`
  to custom group `Сериалы`.
- Keeps the previous 64 unique serial-channel names moved
  from `Кинозалы`.
- Moves `Viasat True Crime CEE` from `Кино` to `Познавательные`.
- Keeps `KBC-Animals HD`, `MM Микромир HD`, `MM Макромир HD`,
  `MM Мегамир HD` in `Познавательные`.
- Keeps `Fresh TV Armenia` in `Музыкальные`.
- `Insomnia HD`: provider M3U uses `Xinsomnia-hd`. The existing hard pin to
  `openbox-tsd/insomnia-hd` produced no final mapping, so v13.18 switches it to
  `runigma-iptv/insomnia-hd`.
- Fixes duplicate compact-title years systemically and idempotently.

## Install

Upload all files preserving folders, commit, then run:

GitHub → Actions → Update EPG → Run workflow

After it finishes, open the playlist once with `/tv?fresh=1`.

Cloudflare code itself does not need a manual edit for the category rules.
