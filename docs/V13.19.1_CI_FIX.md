# v13.19.1 — CI regression update

The failure was caused by a legacy regression test from v11.3.1 that explicitly
required the standalone metadata-backfill workflow to remain manual-only.

That policy is obsolete after v13.19, where nightly smart maintenance is an
intentional architecture change.

The replacement test now requires:
- manual `workflow_dispatch`;
- nightly `schedule`;
- cron `20 11 * * *`;
- shared `epg-metadata` concurrency;
- durable metadata snapshot restore/save;
- commit of the SQLite snapshot and growth reports.

No production code or metadata database is changed by v13.19.1.
