# v13.20 — Consolidated EPG recovery

This is the consolidated patch after manual live verification.

## Fresh
Hard-pins 13 missing Fresh channels:
Fantastic, VHS, Rating, Family, Premiere, Comedy, Kids, Cinema, Horror,
Adventure, Romantic, Russian, Thriller.

## Magic
Current provider playlist contains the Magic movie family:
Premiere, Adventure, Russian, Action, Comedy, Family, Galaxy, Horror, Karate,
Love, Thriller, VHS, plus Magic Disney in Kids.

They are pinned to the matching TSD `magic-*` schedules.
`Magic TV` (Bulgaria) and `jk_Magic` (excluded Ukrainian group) are intentionally
NOT treated as part of this family.

## VeleS
- VeleS С Новым годом! -> Runigma / veles-newyear
- VeleS Movie Hits -> IPTVX / veles-mh
- VeleS DJ Set naming variants -> Музыкальные

## BCU
Pins/identity fixes include:
- Cinema -> bcu-cinema
- Cinema+ -> bcu-cinemaplus
- Marvel -> bcu-marvel
- Russian -> bcu-russian
- Cosmo -> bcu-cosmo
- Media OLD -> BOX Hybrid / box-hybrid
- New Media 2 -> BCU Action / bcu-action
- BCU_UTIFY_1_HDR -> BCU Comedy EPG only; display name is NOT changed
- BCU_UTIFY_2_HD -> bcu-catastrophe and display rename to BCU Catastrophe HD
- BCU_UTIFY_3_HD -> bcu-history and display rename to BCU History HD
- BCU Premiere 3 HDR -> display rename to BCU Fantastic HDR; current EPG mapping is preserved
- BCU Premiere 2 HDR remains review-only because candidate EPG IDs conflict.

## Worker
Worker v2.2 adds `name_overrides`. Crucially it performs EPG mapping lookup using
the ORIGINAL provider channel name first, and only then changes the display name.
This prevents renamed channels from losing their EPG.

Because worker.js changes, this release DOES require one Cloudflare Worker deploy.
After deployment and Update EPG, refresh:
https://iptv-epg.peter96son.workers.dev/tv?fresh=1

No metadata SQLite snapshot is included or reset.
