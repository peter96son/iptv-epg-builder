# v13.24

Two fixes.

## 1. Year-safe movie metadata
When XMLTV supplies a movie year, local knowledge/alias metadata is accepted only when
the resolved work has the same year. A yearless alias can no longer attach IMDb data
from a different adaptation with the same title.

Example protected case: Russian `Шерлок Холмс` vs the 2009 US/UK `Sherlock Holmes`.

## 2. Conditional Ukrainian channel hiding
Nine current Ukrainian movie streams are hidden from `Кино` only while BOTH their
provider name and stable `/play/<id>/` match. The private playlist token is never stored.
If the provider reuses the same play-id for a differently named channel, it appears again.
